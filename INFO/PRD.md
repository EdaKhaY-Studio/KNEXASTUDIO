# PRODUCT REQUIREMENT DOCUMENT

# KNEXU STUDIO

**Product:** KNEXU STUDIO Official Business Website
**Version:** 1.0
**Status:** Product Specification
**Business Location:** Meulaboh, Aceh Barat, Indonesia
**Primary Language:** Bahasa Indonesia
**Platform:** Responsive Web
**Frontend:** React + TypeScript + Tailwind CSS
**UI / Motion:** React Bits
**3D:** Three.js / React Three Fiber when required
**Icons:** Lucide React
**Backend:** Node.js

---

# 01. PRODUCT OVERVIEW

KNEXU STUDIO adalah studio digital yang menyediakan jasa pembuatan website profesional, aplikasi web kustom, serta integrasi AI Customer Service.

Website KNEXU STUDIO berfungsi sebagai:

1. Company profile digital.
2. Portfolio showcase.
3. Service catalog.
4. Pricing presentation.
5. Lead generation platform.
6. Consultation entry point.
7. Demonstration platform untuk teknologi AI.
8. Digital representation dari brand KNEXU STUDIO.

Website harus mampu menjelaskan nilai bisnis KNEXU STUDIO tanpa membuat calon pelanggan harus menghubungi admin terlebih dahulu hanya untuk memahami layanan dasar.

---

# 02. PRODUCT VISION

Membangun website studio digital yang membuat calon pelanggan memahami bahwa mereka dapat memperoleh solusi website profesional dan teknologi AI dengan proses yang sederhana, transparan, dan terjangkau.

Website harus membawa persepsi:

> "Saya bisa mendapatkan website profesional tanpa harus memahami teknologi secara mendalam."

Pada saat yang sama, website harus menunjukkan bahwa KNEXU STUDIO mempunyai kemampuan teknis yang lebih luas daripada sekadar membuat halaman website.

* Excessive glassmorphism
